# HomyWO
Home workout tracker sederhana berbahasa Indonesia.

## Fitur
- Dashboard dan target mingguan
- Log strength workout
- Cardio: skipping, jalan cepat, jogging, sepeda, HIIT
- Progress log berat badan
- Library bodyweight dan dumbbell
- Rekomendasi peralatan ringkas
- Data disimpan lokal pada browser (localStorage)

## Jalankan
Buka index.html atau gunakan server: python -m http.server 8000

## Volcano setup
Starter config dan migration tersedia di folder volcano/. CLI dan kredensial project tidak tersedia di sesi ini, jadi belum terhubung/deploy cloud. Isi volcano.env secara lokal setelah project siap.
